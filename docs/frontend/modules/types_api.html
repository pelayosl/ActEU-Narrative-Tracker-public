    Module types/api

    TypeScript mirrors of the backend Pydantic schemas (app/schemas/*).

    These interfaces are the wire contract between the frontend and the FastAPI backend: every value returned by api (see lib/api-client.ts) is typed with one of the shapes declared here. Field names deliberately match the backend JSON (snake_case) so responses can be consumed without remapping.

    Keep in sync with app/schemas/*.
