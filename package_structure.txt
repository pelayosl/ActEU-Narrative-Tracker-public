Main characteristics
- Domain: ActEU research project; narrative discovery and analysis over multilingual datasets.
- Backend: FastAPI with REST + SSE endpoints; routers under app/api.
- Architecture: API gateway -> services -> repositories (strict layering).
- Data: MongoDB for documents, projects, users; Motor async driver.
- Async jobs: Celery workers with Redis broker; SSE streams for progress.
- NLP: BERTopic, FastText classifier, sentence-transformers embeddings, Gemini API.
- Infrastructure: Docker + Docker Compose; Nginx reverse proxy for deployment.
- Frontend (external): Next.js + Tailwind + Zustand + React Query (per project_context).
